# 03 市区町村分析（e-Stat, N=1,859）

## なぜ市区町村に下りたか

都道府県（N=47）では残差スクリーニングの検出力が足りなかった。375指標を試すと、無関係でも偶然 |r| = 0.53 が出てしまう。N を35倍にすれば閾値が下がるはず、という動機。

## 期待どおりにならなかったこと

**転職率は市区町村まで下りていない。**就業構造基本調査由来の指標（転職率・離職率）は市区町村では公表されていない。市区町村の労働ファイルに入っているのは国勢調査由来の15指標だけ（労働力人口、就業者数、完全失業者数、産業別就業者数、雇用者数、通勤者数など）。

代用として **総移動率 =（転入者数＋転出者数）÷ 住民基本台帳人口**（住民基本台帳人口移動報告）を使った。転職率と同じ「総フロー」の考え方だが、**測っているのは居住移動であって職業移動ではない**。

実際、総移動率の相関相手はこうなる。

| 相関相手 | r |
|---|---|
| 単独世帯割合 | **+0.62** |
| 高齢化率 | −0.42 |
| 1人当たり課税対象所得 | +0.42 |
| 第3次産業就業者比率 | +0.37 |
| 人口密度（対数） | +0.17 |
| **完全失業率** | **−0.14** |

**居住移動は世帯構成で決まる。**単身者は動き、家族世帯と高齢者は動かない。都道府県で見えた「雇用の不安定さ → 転職」の経路は符号ごと再現しない。

## 潜在変数モデルが成立しない

5仕様試して全滅した。

| 仕様 | CFI | RMSEA |
|---|---|---|
| 都市度(密度+3次産業+課税所得) + 雇用不安定さ | 0.770 | 0.218 |
| 都市度 + 年齢構成 | 0.824 | 0.269 |
| 上記 + 単独世帯割合 | 0.808 | 0.254 |
| 過疎度(5指標) + 単独世帯 | 0.682 | 0.319 |
| 過疎度(3指標) + 単独世帯 | 0.885 | 0.236 |

残差相関を見ると `総移動率 ~~ 非雇用者比率 +0.178`、`総移動率 ~~ 高齢化率 −0.122` と、**個々の指標が因子を経由せず結果変数に直接効いている**。反映的測定モデルが間違ったモデルだということ。

理由は §「集計レベルが因子構造を組み替える」（[04-methodology.md](04-methodology.md) §4）にある。都道府県で 0.70〜0.88 だった都市度指標の相互相関が、市区町村では 0.37〜0.62 に落ちる。

## 採用モデル — 観測変数のパス解析

[src/muni_path.py](../src/muni_path.py) / 図 [figures/muni_path_diagram.svg](../figures/muni_path_diagram.svg)

潜在変数を捨て、測定モデルを持たないパス解析（SEMの原型、Wright 1921）に切り替えた。決め手は残差相関から見つけた `通勤流出率 → 単独世帯割合` の経路。ベッドタウンは家族世帯が多く単身が少ない。

```
人口密度 ──→ 通勤流出率 ──→ 単独世帯割合 ──→ 総移動率
   │              │              ↑              ↑
   ├──────────────┴──────────────┘              │
   ├──→ 高齢化率 ───────────────────────────────┤
   └────────────────────────────────────────────┘
```

χ²/df = 1.51 / **CFI = 1.000** / TLI = 0.999 / **RMSEA = 0.016** / 残差相関の最大 0.023

| パス | 標準化係数 | ブートストラップ95%区間 |
|---|---|---|
| 単独世帯割合 → 総移動率 | **+0.766** | [+0.707, +0.822] |
| 高齢化率 → 総移動率 | **−0.442** | [−0.486, −0.396] |
| 通勤流出率 → 総移動率 | **+0.272** | [+0.209, +0.330] |
| 人口密度 → 総移動率（直接） | **−0.352** | [−0.448, −0.268] |
| 通勤流出率 → 単独世帯割合 | **−0.656** | [−0.700, −0.610] |
| 人口密度 → 通勤流出率 | +0.623 | — |
| 人口密度 → 高齢化率 | −0.691 | — |
| 人口密度 → 単独世帯割合 | +0.577 | — |
| 高齢化率 → 単独世帯割合 | −0.108 | — |

全パス p < .001。

## 効果分解 — 打ち消し合う2つの力

| 人口密度 → 総移動率 | 係数 |
|---|---|
| 直接 | −0.352 |
| 単身世帯を増やす経路 | +0.442 |
| 高齢化を抑える経路 | +0.305 |
| 通勤流出→単身減の経路 | −0.313 |
| 高齢化→単身減の経路 | +0.057 |
| 通勤流出経由 | +0.170 |
| **間接合計** | **+0.661** |
| **総効果** | **+0.308** [+0.237, +0.375] |

密度が上がると単身世帯が増えて移動が増える（+0.44）一方、通勤流出も増えてベッドタウン化し、家族世帯が増えて移動が減る（−0.31）。**素の相関（密度×移動率 = 0.14）だけを見ていては見えない構造。**これがパス解析の価値。

## スクリーニング — N が増えて閾値が下がった

重回帰（10予測変数、R² = 0.594）の残差を、人口当たりに直した80指標に総当たりした。

| | 都道府県 | 市区町村 |
|---|---|---|
| N | 47 | 1,604 |
| 指標数 | 375 | 80 |
| 偶然でも出る最大\|r\|（95%点） | **0.529** | **0.094** |
| 閾値を超えた指標 | 2件 → 沖縄を除くと **0件** | **21件 / 80件** |

上位の検出結果:

| 指標（人口当たり） | r |
|---|---|
| 他市区町村への通勤者数 | +0.269 |
| 外国人人口 | +0.239 |
| 薬剤師数 | −0.205 |
| 自市区町村で従業している就業者数 | −0.186 |
| 中学校数 | +0.183 |

ベッドタウンほど移動が多く、職住近接の自治体ほど動かない。解釈可能だが**効果量は最大でも 0.27**で、劇的なものはない。

## データの扱い

- **人口1,000人未満の35自治体を除外。**率が不安定になる（人口0の双葉町、青ヶ島村は総移動率 43%）。
- **政令指定都市・特別区部の合計行（17行）を除外。**区と二重計上になるため、区単位で集計。
- 都道府県行（末尾3桁000、47行）も除外。
- 結果として 1,960行 → 1,896市区町村 → 人口フィルタ後 1,859。

## 限界

- 総移動率は居住移動。職業移動の代理としては弱い。
- 指標の年次が混在する（国勢調査2020 / 住民基本台帳2024 / 経済センサス2021 など）。
- 小規模自治体ほど率の分散が大きい（人口1,000〜5,000のSDは2.61 vs 10万以上の3.32だが、母数が小さいぶんノイズが乗る）。重み付けはしていない。
