# 01 国レベル分析（World Bank, N=128）

## 問い

制度の質は経済成長を生むか。生むとしたら、直接か、人的資本を経由してか。

## 設計

横断データで因果を主張できないので、**説明側を2012年、結果側を2012→2022年の変化**に取って時点をずらした。

| 潜在変数 | 指標 | World Bank コード | 時点 |
|---|---|---|---|
| 制度の質 (GOV) | 法の支配 | `GOV_WGI_RL.EST` | 2012 |
| | 政府の有効性 | `GOV_WGI_GE.EST` | 2012 |
| | 腐敗の抑制 | `GOV_WGI_CC.EST` | 2012 |
| | 規制の質 | `GOV_WGI_RQ.EST` | 2012 |
| 人的資本 (HC) | 平均寿命 | `SP.DYN.LE00.IN` | 2010-14 |
| | 乳幼児生存（5歳未満死亡率の負の対数） | `SH.DYN.MORT` | 2010-14 |
| | 中等教育就学率 | `SE.SEC.ENRR` | 2010-14 |
| その後の成長 (GROWTH) | 一人当たりGDP成長（対数差） | `NY.GDP.PCAP.PP.KD` | 2012→2022 |
| | 一人当たりGNI成長 | `NY.GNP.PCAP.PP.KD` | 2012→2022 |
| | 一人当たり消費成長 | `NE.CON.PRVT.PC.KD` | 2012→2022 |
| 初期所得（観測） | log 一人当たりGDP | `NY.GDP.PCAP.PP.KD` | 2010-14 |

WGI の6指標のうち4つだけを使った。Voice and Accountability（民主的説明責任）と Political Stability（政治的安定）は外している。「行政の実務能力」に寄せる判断で、**民主主義の指標を外すと「制度の質」の意味は変わる**点は明示しておく。

窓（2010-14 など）の中で目標年に最も近い観測値を採用する。単年だと欠損が多いため。

## 初版（Model B）とその問題

[src/sem_analysis.py](../src/sem_analysis.py)

到達点: χ²/df = 2.25 / CFI = 0.975 / TLI = 0.963 / RMSEA = 0.099

| パス | 標準化係数 | p |
|---|---|---|
| 制度の質 → 人的資本 | +0.20 | .001 |
| 初期所得 → 人的資本 | +0.75 | <.001 |
| 人的資本 → 成長 | +0.92 | <.001 |
| 初期所得 → 成長 | **−1.07** | <.001 |
| 制度の質 → 成長 | +0.23 | .118 |

**標準化係数が −1.07。**人的資本と初期所得が因子得点で r = 0.906 あり、両方を成長式に入れたことによる抑制効果。

[src/robustness.py](../src/robustness.py) で4仕様を比較したところ、初期所得を成長式から外すと人的資本の効果が +0.02（n.s.）まで消える。**つまり「人的資本 +0.92」は同じ所得水準の国どうしを比べたときの条件付きの効果**であって、単独では成立しない。

## 到達しなかった代替案

| 案 | 結果 |
|---|---|
| 人的資本と初期所得を1つの「初期の発展水準」に統合 | 抑制は消えるが効果も消える（人的資本→成長 +0.02） |
| 人的資本を教育のみに（中等＋高等） | 相関 0.84。最大\|std\| 1.35 と悪化 |
| 教育のみ（中等＋高等＋初等修了） | 相関 0.83。最大\|std\| 1.17 |
| 保健のみ（寿命＋乳幼児生存） | 相関 0.87。最大\|std\| 1.11 |

**指標をどう入れ替えても相関は 0.83〜0.90 から下がらない。仕様の誤りではなくデータの構造。**

## 採用版（残差化モデル）

[src/sem_country_v2.py](../src/sem_country_v2.py)

人的資本の各指標を初期所得に単回帰し、**残差に置き換えた**。「その所得水準の国として期待される以上に人的資本が厚いか」を測る潜在変数になり、初期所得と定義上直交する。

χ²/df = 2.02 / CFI = 0.972 / TLI = 0.958 / **RMSEA = 0.089** / 最大|std| = 1.00

| パス | 標準化係数 | ブートストラップ95%区間（600回） | 判定 |
|---|---|---|---|
| 所得水準を超えた人的資本 → 成長 | **+0.353** | **[+0.144, +0.544]** | 区間が0を含まない |
| 制度の質 → 所得水準を超えた人的資本 | **+0.190** | **[+0.031, +0.354]** | 区間が0を含まない |
| 制度の質 → 成長（直接） | +0.238 | [−0.040, +0.489] | 区間が0を含む |
| 初期所得 → 成長 | −0.240 | [−0.527, +0.053] | 区間が0を含む |

因子負荷: 制度の質 0.93〜1.00、成長 0.62〜0.92、人的資本（残差化後）0.46〜0.91。中等教育就学率の負荷 0.46 が弱く、**この潜在変数は実質的に保健寄り**である点は注意。

### 所得グループ別

点推定は近いが区間が大きく重なる。**構造が違うとは言えないが、同じだとも示せていない。**グループを割ると N が足りない。

## 副次的な分析

- [src/country_model_check.py](../src/country_model_check.py) — 保存済み Model B の推定値からモデル含意共分散を再構成し、2012年の8指標を条件とした成長の条件付き予測を出す。再推定は行わない。中国を除きサンプル内診断であり、交差検証でも因果でもない。
- [src/country_life_residuals.py](../src/country_life_residuals.py) — 199の国・地域で平均寿命を log 一人当たり実質GDP に回帰した残差。R² = 0.690、残差SD 4.66年。日本 +5.20年、中国 +5.73年、ロシア −6.80年。**これは潜在変数モデルの残差ではなく単回帰の残差**であり、因果効果ではない。

## この分析の限界

- 矢印の向きはデータからは決まらない。時点差は「未来が過去を引き起こした」を排除するだけ。
- 残差化した人的資本は「所得で説明できない部分」であり、人的資本の水準そのものではない。
- WGI は専門家評価・企業調査の合成指標で、測定誤差は小さくない。4指標の相互相関が 0.87〜0.94 と高いのは、同一の原データを共有しているため（残差相関を2本許容してある）。
