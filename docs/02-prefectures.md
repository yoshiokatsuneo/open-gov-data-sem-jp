# 2-1. 健康モデル — 都道府県の健康格差は豊かさか、医療の量か

[src/estat_sem.py](../src/estat_sem.py) / 図 [figures/pref_path_diagram.svg](../figures/pref_path_diagram.svg)

## 指標

| 潜在変数 | 指標 | e-Stat コード | 年 |
|---|---|---|---|
| 経済的豊かさ | １人当たり県民所得 | `#C01321` | 2015 |
| | 課税対象所得（納税義務者1人当たり） | `#D02206` | 2015 |
| | 高等学校卒業者の進学率 | `#E09402` | 2015 |
| 入院医療キャパシティ | 看護師・准看護師数（人口10万人当たり） | `#I0920301` | 2016 |
| | 一般病院病床数（人口10万人当たり） | `#I0910203` | 2015 |
| | 一般病院数（人口10万人当たり） | `#I0910103` | 2015 |
| 結果（観測） | 平均余命（0歳・男） | `#I0520101` | 2015 |
| | 平均余命（0歳・女） | `#I0520102` | 2015 |

**医師数（`#I0920101`）は除外した。**看護師・病床と同じ因子に入れると残差相関が 0.40 出て適合を壊す。医学部の所在に規定される別の変数。ただし医師数と平均寿命(女)の相関は 0.37、男では 0.07 で、ここにも男女差が出ている。

## 結果

χ²/df = 1.73 / CFI = 0.968 / TLI = 0.944 / RMSEA = 0.126 / 残差相関の最大 0.142

| パス | 標準化係数 | ブートストラップ95%区間 | LOO範囲（47通り） | 判定 |
|---|---|---|---|---|
| 経済的豊かさ → 入院医療キャパシティ | **−0.601** | [−0.778, −0.459] | −0.64〜−0.57 | 確立 |
| 経済的豊かさ → 平均寿命（男） | **+0.498** | [+0.252, +0.930] | +0.43〜+0.67 | 確立 |
| 経済的豊かさ → 平均寿命（女） | +0.243 | [−0.128, +0.636] | — | 未確立 |
| 入院医療キャパシティ → 平均寿命（男） | +0.026 | [−0.259, +0.460] | 符号反転あり | 未確立 |
| 入院医療キャパシティ → 平均寿命（女） | +0.243 | [−0.082, +0.642] | — | 未確立 |

**3つの読みどころ。**豊かな県ほど人口当たりの病床・看護師・病院が少ない。経済の勾配は男性にだけ出る。医療の供給量では寿命を説明できない。

## 残差（豊かさから予測される寿命とのずれ）

[src/pref_residuals.py](../src/pref_residuals.py) / 図 [figures/pref_residual_chart.svg](../figures/pref_residual_chart.svg)

豊かさスコアは因子得点ではなく**3指標の標準化平均**。因子得点は課税対象所得の残差分散が 0 に潰れる Heywood ケースで計算できない（結果はほぼ同じ：相関 0.482 vs 0.489）。

| | 県 | 残差(男) | 残差(女) |
|---|---|---|---|
| 最大 | 長野県 | **+1.17** | +0.66 |
| | 滋賀県 | +0.97 | +0.52 |
| | 熊本県 | +0.81 | +0.51 |
| 最小 | 青森県 | **−1.69** | −1.04 |
| | 秋田県 | −0.83 | −0.59 |
| | 東京都 | −0.79 | +0.02 |

豊かさで説明できるのは男性で 24%（R²=0.239）、女性では 2%（R²=0.016）。**女性の残差は実質そのまま平均寿命の順位**であり、豊かさを差し引いた効果ではない。

男女の残差の相関は **0.82**。豊かさの勾配は男性にしか出ないのに、豊かさ以外の要因は男女で共通して効いている。

東京は豊かさスコアが +3.92（2位の愛知 +1.52 の2.5倍）の高レバレッジ点で、予測値が外挿になっている。東京の残差は「東京が不健康」ではなく外挿の産物と読むべき。

# 2-2. 転職モデル — 転職が多い県は労働市場が厚いのか、雇用が不安定なのか

[src/job_sem.py](../src/job_sem.py) / 図 [figures/job_path_diagram.svg](../figures/job_path_diagram.svg)

## 指標

| 潜在変数 | 指標 | e-Stat コード | 年 |
|---|---|---|---|
| 都市労働市場の厚み | 可住地面積1k㎡当たり人口密度（対数） | `#A01202` | 2020 |
| | 流入人口比率 | `#A05304` | 2015 |
| | きまって支給する現金給与月額（女） | `#F0620104` | 2021 |
| 雇用の不安定さ | 離職率 | `#F04102` | 2017 |
| | 完全失業率 | `#F01301` | 2015 |
| 結果（観測） | 転職率 | `#F04101` | 2017 |

**除外した指標と理由。**「就業異動率」は転職率＋新規就業率との相関が 0.97 で定義上重複。「人口集中地区人口比率」は離職率と残差相関 0.29 を残す。「雇用保険受給率」は流入人口比率と残差相関 −0.41。

## 結果

χ²/df = 2.14 / CFI = 0.951 / TLI = 0.895 / RMSEA = 0.157 / 残差相関の最大 0.145

| パス | 標準化係数 | ブートストラップ95%区間 | LOO範囲 | 判定 |
|---|---|---|---|---|
| 都市労働市場の厚み → 転職率 | **+0.496** | [+0.201, +0.748] | +0.42〜+0.61 | 確立 |
| 雇用の不安定さ → 転職率 | +0.390 | [−0.013, +0.699] | +0.16〜+0.44 | 未確立 |
| 都市労働市場の厚み ↔ 雇用の不安定さ | −0.074 | [−0.324, +0.408] | — | 0と区別できない |

**2つの説明側の相関が −0.07。**まったく別の次元として分離する。人口密度と離職率の生の相関も 0.08。

沖縄は都市度が平均以下（−0.37）なのに転職率1位（6.7%）で、不安定さ側（+2.61）だけで到達している。東京は不安定さ −0.86 で、都市度（+4.17）だけで 5.7%。**同じ「転職が多い県」でも中身が違う。**

不安定さ側のパスは沖縄を抜くと +0.39 → +0.16 に落ちる。ブートストラップ区間が0をまたぐことと整合する。

## モデル外の観察

- **有効求人倍率と転職率の相関は −0.36。**高いのは秋田(1.25)・長野(1.16)で、これらは転職率の下位。逼迫と労働移動は別物。
- **離職率と転職率の相関は 0.29 しかない。**離職率は完全失業率と 0.70 で結びつく。離職は「職を失う」側の現象。

## 残差とスクリーニング

重回帰 R² = 0.334、残差SD 0.451pt。沖縄 +1.54pt（3.4σ）が最大、和歌山 −1.13pt が最小。

残差を375指標に総当たりした結果は [docs/04-methodology.md](04-methodology.md) の §2-3 に詳述。**沖縄を除くと閾値超えは0件。**

地方別に残差が偏って見えるが（近畿 −0.34、四国 −0.41 vs 九州 +0.25、関東 +0.23）、地方間分散の並べ替え検定で **p = 0.201**。偶然と区別がつかない。
