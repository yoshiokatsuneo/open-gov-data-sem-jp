# 推定の健全性と男女差の追加検証

## 範囲

既存の4モデルと固定データを維持し、`src/sem_audit.py` で元標本とブートストラップの各反復を監査する。今回の変更は標準的な追加検証であり、モデル選択の全過程・空間依存・因果識別を検証し直したものではない。

- 最適化結果の成功フラグ
- 係数・標準化係数・目的関数の有限性
- 負の分散がないこと（許容誤差 1e-8）
- モデル含意共分散が正定値であること
- 分散の絶対値が1e-8以下の境界解を別途記録

主要パスのブートストラップにも同じ採否判定を組み込んだ。境界解は単純な収束失敗とは区別して残す。情報行列の健全性・局所最適性・境界における区間の被覆率まで保証する基準ではない。

## 男女の係数差

健康モデルを同じ再抽出標本で推定し、男性の係数から女性の係数を引く。寿命を元の年単位に戻した差を主比較とし、標準化係数差は参考値とする。因子の尺度は元標本の基準指標の1標準偏差に対応するよう固定されている。豊かさと医療供給量は異なる尺度なので、両者の差の大きさを直接比較しない。

豊かさと医療供給量の2比較について、通常の95%区間に加えBonferroni対応の各97.5%パーセンタイル区間を示す。分析結果を見た後の追加比較であり、事前登録された確認的検証ではない。1県抜きで差が変わる範囲も示す。これは各LOO推定の信頼区間ではない。

境界解を含む基本条件通過反復を主結果とし、境界解を除いた区間も参考として残す。後者は反復の選別を伴うため「より正しい区間」とは扱わない。元の標準化・残差化を固定した条件付きの検証であり、前処理やモデル選択の不確実性は含まない。
