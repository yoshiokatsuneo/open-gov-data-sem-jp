## 1. 範囲制限 — 一度これで誤った結論を出し、撤回した

### 何が起きたか

国レベル（128か国）で「人的資本」と「経済的繁栄」が標準化係数 0.97 で潰れ、別々の潜在変数として立てられなかった。一方、47都道府県では所得と平均寿命(女)の相関が 0.06 しかなく、きれいに分離した。

そこで **「分析単位が変わると豊かさと健康は別物になる」** と結論づけた。**これは間違いだった。**

### 検算

```python
import sys; sys.path.insert(0, "src")
import numpy as np, pandas as pd, paths

c = pd.read_csv(paths.result("sem_sample.csv")).dropna(subset=["gdp_pc_12", "life_exp_12"])
c["lg"] = np.log(c.gdp_pc_12)
for q, lab in [(0, "全128か国"), (.5, "上位50%"), (.75, "上位25%"), (.85, "上位15%")]:
    s = c[c.gdp_pc_12 >= c.gdp_pc_12.quantile(q)]
    print(f"{lab:10s} n={len(s):3d} レンジ={s.gdp_pc_12.max()/s.gdp_pc_12.min():5.1f}倍 "
          f"r={np.corrcoef(s.lg, s.life_exp_12)[0,1]:+.3f}")
```

| 絞り込み | n | 所得レンジ | 所得×平均寿命 |
|---|---|---|---|
| 全128か国 | 128 | 109.0倍 | **+0.845** |
| 上位50% | 64 | 8.5倍 | +0.632 |
| 上位25% | 32 | 3.6倍 | **+0.070** |
| 上位15% | 20 | 2.7倍 | −0.141 |

47都道府県の所得レンジは **2.63倍**（226万〜586万円）、所得×平均寿命(女) は **0.06**。

**国データを都道府県と同じ所得レンジに絞るだけで、0.845 が 0.07 に落ちる。**分析単位の違いではなく、単に範囲が狭いと相関が減衰する（range restriction）だけだった。都道府県を比べるのは、豊かな国の上位25%どうしを比べるのと統計的にほぼ同じ状況。

健康側も同じで、平均寿命の変動係数は国 0.119 に対し都道府県(女) 0.005。**20分の1以下しか動いていない。**

### 正しい言い方

❌ 「豊かさと健康は都道府県では別次元」
✅ 「日本国内の所得差は、健康差を検出するには狭すぎる」

独立なのではなく、見えないだけ。

### 教訓

**分析単位を変えて相関が変わったら、まず各変数のレンジ比（最大/最小、変動係数）を比べる。**2倍を切るなら、効果を検出できると期待しないほうがいい。

## 2. 多重比較 — N=47 で375指標なら、無関係でも |r| = 0.53 が出る

### 手順（[src/job_screen.py](../src/job_screen.py) が実装）

探索するときは目についた指標を拾ってはいけない。

1. 47都道府県そろう**全指標**を機械的に相関させる（モデル自身の指標と、定義上重複するものだけ除外）
2. 結果変数を並べ替えて「全指標中の最大 |r|」の帰無分布を **2,000回** 作る
3. その95%点を閾値にする

並べ替え方式を使う理由は、**指標間の相関が自動で織り込まれる**から。Bonferroni は保守的すぎ、BH-FDR は独立性を仮定する。

### 結果

| | 都道府県 | 市区町村 |
|---|---|---|
| N | 47 | 1,604 |
| 指標数 | 375 | 80 |
| 帰無分布の最大\|r\| 中央値 | 0.415 | — |
| **95%点（閾値）** | **0.529** | **0.094** |

**「r = 0.5 の相関を見つけた」は、この設定では何も意味しない。**

## 3. 1点の影響 — leave-one-out を必ず通す

### 何が起きたか

転職モデルの残差を375指標に総当たりしたところ、全47県では2指標が閾値を超え、しかも上位15件はテーマが揃っていた（若さ・人口成長・地価上昇）。「地域の若さと成長が転職を押し上げる」という筋の通る解釈まで書けた。

1県ずつ抜いてみたらこうなった。

| 指標 | 全47県 | 沖縄を除く46県 |
|---|---|---|
| 工業地地価変動率 | +0.594 | **+0.356** |
| 15歳未満人口割合 | +0.536 | **+0.313** |
| 住宅地地価変動率 | +0.506 | **+0.204** |
| 粗出生率 | +0.477 | **+0.220** |

沖縄を除いて375指標のスクリーニングをやり直すと、閾値 0.523 に対し最大が 0.498 で **該当ゼロ件**。しかも上位の顔ぶれが完全に入れ替わる。**順位が1点で入れ替わるのは、そこに構造がない証拠。**

### なぜこうなるか

沖縄は残差 **+1.54pt（3.4σ**、2位の千葉 +0.85pt を大きく離す）であると同時に、人口増減率・自然増減率・住宅地地価変動率すべてで**全国1位**。住宅地地価変動率は 4.00% で2位に +3.20 ポイント差。**結果側でも説明側でも最も極端**なので、この1点だけで相関が立つ。

### 正しい言い方

沖縄は入力ミスでも外れ値処理の対象でもなく、実在する県。「除くのが正しい」わけではない。正確には **この関係の根拠は観測1つ分しかない**。

## 4. 集計レベルは因子構造を組み替える

### 検算

両レベルに存在する7指標（人口密度・第3次産業比率・課税所得・完全失業率・単独世帯割合・高齢化率・年少人口割合）で21ペアの相関を比較した（[src/make_muni_chart.py](../src/make_muni_chart.py) の `pairs()`）。

| ペア | 都道府県 (N=47) | 市区町村 (N=1,690) |
|---|---|---|
| 密度 × 課税所得 | 0.880 | 0.454 |
| 密度 × 単独世帯 | 0.523 | **0.049** |
| 単独世帯 × 高齢化率 | −0.384 | −0.076 |
| 失業率 × 単独世帯 | **+0.325** | **−0.050**（符号反転） |
| 3次産業 × 単独世帯 | 0.617 | 0.354 |
| ... | | |
| 密度 × 失業率 | 0.083 | **0.323**（逆に強まる） |
| 高齢化率 × 年少人口 | −0.555 | **−0.773**（逆に強まる） |

|r| の平均は都道府県 0.372 / 市区町村 0.304。**21ペア中12件は都道府県で強く、9件は市区町村で強い。**

### 教訓

**「集計すると相関が水増しされる」は不正確。正しくは「組み替えが起きる」。**

密度×単独世帯が 0.52 から 0.05 に消える一方、密度×失業率は 0.08 から 0.32 に現れる。**どの変数がどの変数と束になるかは、現象の性質ではなく集計単位の性質。**

都道府県で成立した「都市労働市場の厚み」という潜在変数は、47点に集計したときにだけ存在していた。市区町村では同じ指標が因子にまとまらず、反映的測定モデルが全滅する（[03-municipalities.md](03-municipalities.md)）。

## 5. 矢印の向きはデータからは決まらない

### 検算

```python
import sys; sys.path.insert(0, "src")
import semopy
from estat_sem import wide, USED

w = wide(); z = (w[USED] - w[USED].mean()) / w[USED].std()
BASE = """WEALTH =~ income + tax_income + univ_rate
MED    =~ nurses + beds + hosp
le_m ~~ le_f
"""
for name, extra in [
    ("豊かさ → 医療キャパ", "MED ~ WEALTH"),
    ("医療キャパ → 豊かさ", "WEALTH ~ MED"),
    ("豊かさ ↔ 医療キャパ", "WEALTH ~~ MED"),
]:
    m = semopy.Model(BASE + extra + "\nle_m ~ WEALTH + MED\nle_f ~ WEALTH + MED")
    m.fit(z); s = semopy.calc_stats(m).T["Value"]
    print(f"{name:20s} χ²={s['chi2']:.4f} df={int(s['DoF'])} "
          f"CFI={s['CFI']:.4f} RMSEA={s['RMSEA']:.4f} AIC={s['AIC']:.4f}")
```

| 仕様 | χ² | df | CFI | RMSEA | AIC |
|---|---|---|---|---|---|
| 豊かさ **→** 医療キャパ | 27.7487 | 16 | 0.9679 | 0.1263 | 38.8192 |
| 医療キャパ **→** 豊かさ | 27.7488 | 16 | 0.9679 | 0.1263 | 38.8192 |
| 豊かさ **↔** 医療キャパ | 27.7488 | 16 | 0.9679 | 0.1263 | 38.8192 |

**区別がつかない。**係数も3つとも −0.6012 で同一（χ² の末尾の差は最適化の丸め誤差）。

### 教訓

SEM が検定しているのは**共分散行列を再現できるかどうか**だけ。同じ共分散行列を再現する等価モデルは無数にある。**適合度が良い ≠ モデルが正しい。**

矢印を正当化できるのは統計ではなく設計。このリポジトリの国レベル分析が多少マシなのは、2012年の条件で2012→2022年の成長を予測する並びにしてあるから（「未来が過去を引き起こした」を排除できる）。都道府県・市区町村は同時点なので、この防御すらない。

## 6. 確認バイアス — 止めるタイミングが偏る

確認バイアスの作動経路は3つあり、3番目が一番強力で一番気づきにくい。

1. 探す場所が偏る
2. 見つけたものの評価が偏る
3. **止めるタイミングが偏る** — 予想と違えば調べ続け、予想通りなら止める

### 実際に起きたこと

| | 予想 | やったこと |
|---|---|---|
| 国レベル | **外れた**（0.97 で潰れた） | 指標入れ替え、結果変数の変更、共分散追加、残差相関追加、頑健性チェック。**20仕様以上** |
| 都道府県 | **当たった**（0.06 で分離） | 「予想が当たって」と書き、発見そのものを**一度も疑わなかった** |

同じ分析者が、同じ日に、都合の悪い結果には20回粘り、都合の良い結果には0回しか反論を試していない。**範囲制限（§1）を4日間見落としたのはそのため。**手元にあったCSVで4行のコードで確認できたのに、探すのをやめていた。

### 近い概念

- **HARKing** — 結果を見てから仮説を作り、最初からそう予想していたことにする
- **garden of forking paths** — 分岐が多すぎて、意識せずとも都合の良い経路を選ぶ。387指標から選べた時点で直撃圏内
- **p-hacking** — 有意になるまで仕様を変える

### 防ぎ方

1. 事前に何をどう検証するか決める
2. 総当たりで頑健性を見る（§2、§3）
3. **自分の発見を壊しにいく**

3つ目が効く。実際、21ペアの総当たり（§4）と並べ替え検定（§2）は部分的な防御になったが、**問いそのものは一度も疑っていなかった**ので range restriction をすり抜けた。

## 7. 実装上のつまずき

### semopy の因子得点が計算できない

`predict_factors` が `LinAlgError: Singular matrix` で落ちる。原因は特定指標の残差分散が 0 に潰れる Heywood ケース（都道府県の健康モデルでは課税対象所得が 2.8e-16、転職モデルでは給与(女)）。

**対処: 因子得点の代わりに指標の標準化平均を使う。**結果はほぼ同じで（平均寿命(男)との相関 0.482 vs 0.489）、そのほうが透明。

### 標準化係数が ±1 を超える

説明変数間の多重共線性による抑制効果。国レベルで −1.07 が出た。

**対処: 残差化。**片方を他方に単回帰した残差に置き換えると定義上直交し、抑制が消える（[01-countries.md](01-countries.md)）。指標の入れ替えでは解決しないことを4仕様で確認済み。

### CFI が 1 を超える

semopy は CFI を 1 でクリップしない。1.009 のような値は χ² < df、つまり自由度が減って飽和モデルに近づいただけで「当てはまりが良くなった」のではない。**適合度指標だけ見て仕様を選ぶとここで誤る。**

### N が大きいと χ² 検定が通らない

市区町村（N=1,859）では、わずかなミススペックでも χ² が跳ねる。RMSEA と残差相関を主に見るべき。逆に N=47 では RMSEA が過大に出る（小標本バイアス）ので、ブートストラップ区間を優先する。
